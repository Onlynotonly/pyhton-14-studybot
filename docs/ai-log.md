# ClassPulse｜AI 協作紀錄

## 紀錄 1：從提醒機器人到主動式行動助手

- **工具**：ChatGPT
- **需求**：結合 LINE 主動提醒、課後回饋、學習戳記與 Deadline 規劃，降低手動管理進度的時間成本。
- **AI 協助**：建議拆成主動互動、資料蒐集、結構化儲存、追蹤、規劃等模組。
- **人的判斷**：不以提醒次數當成價值；回饋頻率不能直接代表知識理解；MVP 先聚焦學習情境。
- **反思**：應以可觀察的操作時間、使用率、建議採用率，而不是憑空宣稱學習成效。

## 紀錄 2：助教回饋後加入產品內 AI

- **工具**：ChatGPT
- **問題**：原本只做 JSON → Markdown 匯出，對競賽而言產品缺乏 AI 推論能力。
- **AI 協助**：提出從筆記辨識未解問題，給出有來源筆記 ID 的複習任務建議。
- **人的判斷**：AI 只負責語意理解；排程仍由確定性的規則完成。AI 建議先由使用者確認，避免直接更動既有計畫。
- **反思**：讓「主動蒐集 → AI 分析 → 人工確認 → 排程」形成完整閉環，卻不需要做大型自主 Agent。

## 紀錄 3：JSON 安全寫入與 LINE 去重

- **工具**：ChatGPT
- **問題**：Streamlit／Flask／Worker 多程序可能同時更新 JSON；Webhook 重送可能重複建立筆記。
- **AI 協助**：建議 filelock 鎖檔、暫存檔後原子替換；將筆記與 webhook_event_id 存同一檔案。
- **人的判斷**：本期單台測試機低併發 Demo 使用 JSON；未來跨機部署應改資料庫，不宣稱跨檔交易或正式商用可靠性。
- **反思**：範圍先收斂到可驗證的功能，避免過度設計。

> 此檔為依討論內容整理的協作摘要。若課堂要求逐字提示詞或 Copilot 對話，應從實際聊天紀錄補上完整提示詞、實際輸出與個別程式修改紀錄；勿將摘要當成逐字對話。
